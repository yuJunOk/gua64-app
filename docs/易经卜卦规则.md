# 易经卜卦规则

## 一、起卦方法：三枚硬币摇卦法

### 工具准备
- 硬币：三枚面值、大小相同的硬币（推荐一元硬币）
- 纸笔：用于记录每次摇卦的结果
- 环境：安静、整洁的桌面，保持心境平和

### 操作步骤

#### 1. 定阴阳
- 设定硬币的一面为"阳"（如：有数字的一面），另一面为"阴"（如：有花或国徽的一面）
- 关键规则：一旦设定，整个占卜过程不可更改

#### 2. 摇卦
- 将三枚硬币置于双手掌心，静心默念所问之事
- 摇晃后抛在桌面上，观察正反面组合
- 记录顺序：从下往上记录，即第一次为初爻（最下），第六次为上爻（最上）

#### 3. 判定爻性

| 硬币组合 | 数值 | 爻性 | 符号 | 说明 |
|---------|------|------|------|------|
| 1阳 2阴 | 7 | 少阳 | — | 阳爻，不变 |
| 2阳 1阴 | 8 | 少阴 | - - | 阴爻，不变 |
| 3阳 0阴 | 9 | 老阳 | — ○ | 阳爻，动，变阴 |
| 0阳 3阴 | 6 | 老阴 | - - × | 阴爻，动，变阳 |

#### 4. 成卦
- 重复上述步骤6次，得到六个爻，自下而上排列，即得本卦
- 若有动爻（老阴或老阳），该爻阴阳互变，所得新卦为变卦（又称之卦、悔卦）

## 二、解卦规则：朱熹解卦法

根据动爻数量进行解卦的七种情况：

### 1. 六爻皆不变（无动爻）
- 规则：以本卦卦辞解之

### 2. 一爻变
- 规则：以本卦变爻爻辞解之

### 3. 二爻变
- 规则：以本卦两个变爻爻辞解之，但以上爻（位置靠上的变爻）为主

### 4. 三爻变
- 规则：以本卦卦辞与变卦卦辞合参，本卦为贞（体），变卦为悔（用）

### 5. 四爻变
- 规则：以变卦中两个不变爻的爻辞解之，以下爻为主

### 6. 五爻变
- 规则：以变卦中唯一不变爻的爻辞解之

### 7. 六爻全变
- 规则：
  - 若为乾卦，用"用九"辞："见群龙无首，吉。"
  - 若为坤卦，用"用六"辞："利永贞。"
  - 其他卦，以变卦卦辞解之

## 三、宜变之爻计算法

### 计算公式
N = 55 - Σ(六爻数值)

注：55为天地之数（1+2+…+10 = 55）。六爻数值即摇卦时记录的6、7、8、9。

### 确定位置
1. 计算六爻数值总和
2. 用55减去总和，得到余数N
3. 定位规则：
   - 若1 ≤ N ≤ 6：第N爻为宜变之爻（从下往上数）
   - 若N > 6：N - 6 = M，继续减6，直至余数在1-6之间
   - 若N = 0或N为6的倍数：通常视为无宜变之爻或按无动爻处理

### 实际应用
宜变之爻计算法主要用于验证或在多爻变时寻找关键线索，不可完全替代实际摇出的动爻。若计算结果与实际动爻不符，以实际动爻为准，计算结果仅作"潜在影响"参考。

## 四、常见术语解释

| 术语 | 解释 |
|------|------|
| 本卦 | 起卦时最初得到的卦象，代表事物的现状、起因或开始 |
| 变卦 | 又称之卦、悔卦。由本卦动爻变化后得到的新卦，代表事物的结果、趋势或未来 |
| 动爻 | 老阴（6）或老阳（9）。物极必反，老阴变阳，老阳变阴，是卦象变化的触发点 |
| 静爻 | 少阴（8）或少阳（7）。性质稳定，不发生变化 |
| 贞/悔 | 贞指内卦（下三爻）或本卦，主静、主内、主我；悔指外卦（上三爻）或变卦，主动、主外、主彼 |
| 应爻 | 初与四、二与五、三与上互为应爻。一阴一阳为"有应"，吉；同阴同阳为"无应"，凶或阻滞 |

## 五、注意事项

1. **一事一占**：每次占卜仅限一个明确问题，不可同时问多事或反复问同一事（"初筮告，再三渎，渎则不告"）
2. **心诚则灵**：起卦时需专注，排除杂念，问题表述应具体、客观，避免模棱两可
3. **客观记录**：严格按照硬币组合记录，不可因期望结果而主观修改爻性
4. **解卦逻辑**：严格遵循朱熹解卦法的七种情形，不可随意跳跃；多爻变时务必结合本卦与变卦
5. **宜变之爻的辅助性**：不可完全替代实际摇出的动爻，仅作参考
6. **时效性**：卦象反映当前时空下的趋势，若客观环境发生重大变化，需重新起卦
7. **学术态度**：易经卜卦为传统文化中的决策参考系统，应保持理性、客观的学术态度，不可迷信
